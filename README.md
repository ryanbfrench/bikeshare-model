# bikeshare-model
An analytical reveiw of Philadelphia Indego Bike ridership.\
Formatted as a jupyter notebook, I provide the following analyses about Philly's bike ridership program, Indego:
- Superfluous stations
- Most popular ridership times
- Prophet model for restocking bikes
- Clustering trips
- Clustering stations

This file must be downloaded locally to view, it's roughly 72 MB
